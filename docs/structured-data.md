# Structured data inventory

- Homepage: truthful `Organization` and `WebSite` objects plus a `SearchAction` whose target is the working, canonicalizing ZIP lookup route.
- FAQ: `FAQPage` generated from the same visible question-and-answer data.
- Guide pages: `Article` with MoveIn as organizational author/publisher, canonical main entity, and visible publication/review dates.
- Secondary pages: `BreadcrumbList` generated by the visible Breadcrumbs component.
- Homeowner, renter, Learn Your Area, and resource hubs: `CollectionPage` with visible guide or resource members.
- ZIP results: `WebPage`, `BreadcrumbList`, `FAQPage`, and `Service`; FAQ answers are rendered visibly on the same page. `Service` describes MoveIn's informational lookup—not utility delivery—and says exact-address confirmation is required.

MoveIn does not emit LocalBusiness, Product, Review, AggregateRating, or invented provider service-area claims. Validate after deployment with Google Rich Results Test and Schema.org Validator; structured data can aid understanding but does not guarantee a rich result.
