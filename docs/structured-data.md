# Structured data inventory

- Homepage: truthful `Organization` and `WebSite` objects.
- FAQ: `FAQPage` generated from the same visible question-and-answer data.
- Guide pages: `Article` with MoveIn as organizational author/publisher, canonical main entity, and visible publication/review dates.
- Secondary pages: `BreadcrumbList` generated by the visible Breadcrumbs component.
- ZIP results: `WebPage`, `BreadcrumbList`, and `FAQPage`; FAQ answers are rendered visibly on the same page.

MoveIn does not emit LocalBusiness, Product, Review, AggregateRating, or invented service-area claims. SearchAction is omitted because there is no general site-search experience. Validate after deployment with Google Rich Results Test and Schema.org Validator; structured data can aid understanding but does not guarantee a rich result.
