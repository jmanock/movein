# Weekly Search Console and GA4 growth workflow

Use comparable date ranges and preserve prior snapshots. Small numbers are directional signals, not proof of rankings, conversions, or product-market fit.

1. Export or read Search Console page and query data.
2. Identify pages with growing impressions, clicks, and query breadth.
3. Group queries by the user problem rather than exact wording.
4. Identify pages approaching first-page positions and pages with impressions but weak click-through rate.
5. Use GA4 landing-page reports to confirm actual visits to those pages.
6. Review engagement without treating time alone as success.
7. Review privacy-safe ZIP-lookup outcomes.
8. Review official provider checks, comparisons, and saves.
9. Review My Move use, printable actions, and returning visitors.
10. Choose one bounded sprint from the combined evidence and record the decision.

## Decision categories

### Double down

Pages gaining relevant impressions and measurable engagement. Improve depth, task completion, and natural connections to the product without replacing a successful URL.

### Improve CTR

Pages earning competitive impressions but few clicks. Review query fit, title, description, and direct-answer clarity. Do not use clickbait.

### Improve content

Pages receiving real visits but showing weak engagement or few useful actions. Find the missing user step before adding more words.

### Expand cluster

Distinct supporting questions surrounding a proven page. Add a page only when it owns a different intent and can provide standalone value; otherwise improve the winner.

### Ignore for now

Tiny, irrelevant, ambiguous, or one-off query tests that do not match MoveIn's mission. Do not generate pages to chase them.

## Weekly output

Record the comparison date, date range, page metrics, query themes, GA4 landing visits, useful actions, the chosen category, the change made, and the metric to revisit. Search Console and GA4 answer different questions: visibility versus measured on-site behavior.
