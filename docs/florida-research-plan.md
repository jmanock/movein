# Florida research plan

The current pilot contains 50 ZIP records across Seminole, Orange, Volusia, Lake, and Osceola counties. Twelve are verified and indexable; 38 are pending and noindex. Expansion follows the generated queue in `data/florida/research-queue.csv`.

Priority is electricity first; water and sewer second; trash third; internet provider/technology evidence fourth; and additional jurisdiction detail last. Review exact-address or parcel tools when available and store unresolved overlaps as research notes rather than selecting a winner.

Near-term work:

1. Work through the 25 pending ZIPs using authoritative utility-boundary and jurisdiction sources.
2. Add electric, water, sewer, and trash records only when the source supports the stated limitation.
3. Add address-supported internet provider and technology observations without speeds, prices, rankings, or affiliate links.
4. Promote a ZIP only after all core categories pass validation and a rendered page review.

Generate a fresh queue after each reviewed import. A utility task leaves the queue only when a non-lookup provider record exists for that category; the local-government task leaves when an official city or county resource is present.
