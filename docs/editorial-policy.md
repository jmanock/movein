# Editorial operations

Every provider or territory statement needs an official source, retrieval date, verification date, uncertainty label, and reviewer decision. ZIP-level evidence must not be rewritten as property-level certainty. New guides need a direct answer, distinct search purpose, three substantive sections, review dates, related links, and official resources when the task has an authoritative source.

Corrections enter a private review queue and never change public data automatically. Paid inclusion cannot alter ranking or replace source-backed information. Run data validation, duplication, SEO, build, and runtime link checks before release. See the public `/editorial-policy` and `/data-sources` pages for visitor-facing language.
