# Internet comparison experience

## User journey

1. `/internet` explains the difference between a ZIP shortlist and an address result.
2. A ZIP lookup shows only market-supported providers associated with that ZIP.
3. Provider cards are alphabetized and divided into wired and wireless home Internet.
4. `/internet/compare` presents connection type, address checker, transfer option, installation considerations, and last review date side by side.
5. Every primary outbound action goes to the provider's official address checker in a new tab.

## Saved comparison

Visitors can save up to four providers in `movein:internet-comparison:v1`. Storage is browser-only, contains no address, email, phone, account information, or notes, and is not synced to MoveIn. The saved list restores on return and can be cleared at any time.

## My Move

Saving a provider to My Move stores only the public provider name. Internet tasks cover comparing providers, checking the exact address, scheduling installation, confirming installation, and recording support details privately. The exact street address and installation date are not stored by MoveIn.

## Neutrality controls

- Alphabetical provider ordering.
- No star ratings, “best” labels, editor choices, sponsored ranking, prices, or affiliate parameters.
- Market evidence never becomes a claim of address service.
- Official lookup tools are visually separated from commercial options.
- Empty provider groups are omitted.

## Mobile behavior

Provider and comparison cards stack vertically; factual definitions remain inside each card rather than forcing a wide table. Buttons retain touch-friendly sizing and full labels.
