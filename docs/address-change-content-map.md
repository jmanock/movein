# Address-change content map

MoveIn uses one page for the broad search intent and gives supporting pages distinct jobs. This prevents several near-identical pages from competing with one another.

| User need | Canonical page | Distinct role |
| --- | --- | --- |
| Change an address after moving | `/resources/change-your-address` | Flagship guide, official-source sequence, interactive progress, FAQs |
| Print or mark every address update | `/resources/printables/address-update-checklist` | Browser-local checkboxes, completion count, reset, print/PDF, bulk add to My Move |
| Keep the new address and contacts on paper | `/resources/printables/new-address-information-sheet` | Blank private worksheet, not a competing guide |
| Browse moving administration by category | `/resources/moving-admin` | Services, rental/home, and planning task hub |
| Catch commonly forgotten work | `/resources/things-people-forget-when-moving` | Broader reminder intent, not a second address guide |
| Coordinate the entire move | `/my-move` | Browser-local plan containing address and other move tasks |

`/change-of-address` redirects permanently to the flagship guide. New bank, insurance, USPS, “who to notify,” campaign, or location variants should not be published unless Search Console shows a genuinely distinct need and the page can provide materially different value. Supporting pages should link back with descriptive anchors, not repeat the flagship prose.
